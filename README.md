# PuttTrainer
Version 1 of PuttTrainer. Made with 1 ESP32 and 3 IR breaking sensors. Only setup for RH golfers. Connect to the devices wifi signal and access it's ip address. Here you will see feedback on your putts and be able to reset the device.
